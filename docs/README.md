# Public Documentation

The `docs/` directory contains public, user-facing documentation.

The documentation entry point is [`index.md`](index.md).

## Intended Content

Use this documentation package for verified information that helps users understand or use a project, including:

- Getting started
- User guides
- Features
- Configuration
- Public APIs
- Tutorials
- FAQ
- Troubleshooting
- Public release notes
- User-visible updates

This directory is not the repository's private development workspace. Project-development and management material is maintained separately under `project/`.

## Template State

The Vib Project Template is a blank project foundation, so most public documentation sections are placeholders until a generated project has real user-facing content to publish.

`docs.manifest.ygit` describes this documentation package for DPMS-compatible tooling. The package remains in `draft` status until its public documentation is ready for publication.
