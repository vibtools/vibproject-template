# Vib Project Template Documentation

The Vib Project Template is a technology-neutral repository foundation for creating software projects with a consistent directory and documentation layout.

## What the Template Provides

The template provides standard locations for:

- Project source code
- Automated tests
- Project scripts
- Assets and configuration
- Public examples
- Public user documentation
- Project metadata through `vibproject.ygit`

It does not choose a programming language, runtime, framework, package manager, or deployment model for the project that uses it.

## Documentation Package

This `docs/` directory is the public documentation package for the template and for projects derived from it.

The current template includes these public documentation sections:

- Getting Started
- Guides
- Features
- Configuration
- API Reference
- Tutorials
- FAQ
- Troubleshooting
- Release Notes

Because this repository is a blank template, a section may remain empty until a real project has verified user-facing information for that section.

## Where to Start

For a high-level view of the repository layout, read the root `README.md`.

For the detailed structural standard, read `PROJECT_STRUCTURE.md` at the repository root.

The public documentation package itself is described by `docs.manifest.ygit` using DPMS v1.
